DEALBOT V6 — QUICK START

1. Extract this V6 folder. Keep V5.1 as your backup.
2. Double-click install_and_start.bat.
3. It creates a private Python environment, installs dependencies, and automatically downloads Playwright Chromium.
4. It attempts to copy the existing V5 .env without overwriting anything. If none is found, copy .env.example to .env and add your Discord/eBay credentials.
5. Run start_bot.bat on later starts.
6. Use /status in Discord. The bot scans automatically; /scanram and /scangpu are optional manual checks.

Optional setup is explained in README.md: Best Buy, approved Reddit access, Slickdeals RSS, Zoho app password, Micro Center store ID, and exact-model sold comps.
